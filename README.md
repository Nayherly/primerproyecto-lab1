OBJETIVO DEL LABORATORIO:
Configurar el entorno de desarrollo e inicializar un repositorio utilizando Git y GitHub, estableciendo una estructura base para proyectos en Node.js.

HERRAMIENTAS UTILIZADAS: 
Node.js
Git
GitHub
Visual Studio Code

PASOS REALIZADOS: 
Se instaló Node.js en su versión LTS y se verificó su funcionamiento mediante comandos en consola.
Se instaló Git y se configuró la identidad del usuario (nombre y correo).
Se instaló Visual Studio Code.
Se creó una carpeta de proyecto y se inicializó un repositorio local con Git.
Se agregaron los archivos del proyecto al área de preparación (staging).
Se realizó el primer commit con un mensaje descriptivo.
Se creó un reposorio remoto en GitHub.
Se conectó el repositorio local con GitHub mediante git remote.
Finalmente, se subieron los archivos al reposorio remoto usando git push.

COMANDOS UTILIZADOS EN GIT 
#Iniciar repositorio --> Git init
#Ver estado de los archivos --> Git status
#Agregar archivos al staging --> git add
#Realizar commit --> git commit -m "Primer commit"
#Conectar repositorio --> git remote add origin (mi cuenta git)
#Verificar que estas en la rama Main --> git branch -M main
#Subir proyecto a Github --> git push -u origin main
#traer cambios de github --> git pull
